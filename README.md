# Jump Break

[Играть и установить приложение](https://w0rkl.github.io/jump-break/)

Автопрыжки, управление стрелками или A/D, пробел — пауза. На телефоне удерживайте стрелки.

Это готовая статическая версия приложения. После первого открытия игра доступна без интернета. Обновление применяется после закрытия всех окон игры.
