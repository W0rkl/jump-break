# Break Arcade

[Играть и установить приложение](https://w0rkl.github.io/jump-break/)

Jump: стрелки или A/D, пробел — пауза. Stack и Flappy: пробел или тап — действие, P — пауза. Три уровня сложности и отдельные локальные рекорды.

Это готовая статическая версия приложения. После первого открытия все три игры доступны без интернета. Обновление применяется после закрытия всех окон игры.
